# 鹈鹕骑车 (Pelican Bike)

横屏侧视跳跃躲障小游戏。Kotlin + Jetpack Compose Canvas。

- 包名：`com.zts.pelicanbike`
- 版本：0.2.0 (versionCode 1)
- 玩法：点按跳跃，躲开上下柱；最高分本地 DataStore 持久化

```bash
. /home/box/tools/env.sh   # 或本机 JDK17 + Android SDK
./gradlew :app:assembleDebug
```

APK：`app/build/outputs/apk/debug/app-debug.apk`
